BEAN & BLOOM — COFFEE SHOP DEMO

FILES
- index.html: page content and structure
- css/master.css: styles and responsive layout
- script.js: shopping cart interactions

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted "coffee_shop_complete" folder in VS Code.
3. Keep the folder structure exactly as it is:
   coffee_shop_complete/
     index.html
     script.js
     css/
       master.css
4. Open index.html with Live Server, or open it directly in a browser.

NOTES
- Images load from Unsplash, so an internet connection is needed for them.
- Product prices are sample prices in USD.
- The cart works in the browser, but this demo does not submit real orders,
  accept payments, or save the cart after refreshing.
- Replace the sample address and email before using this for a real business.
